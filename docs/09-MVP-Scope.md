# MVP Scope (Competition Version)

## 1. Included Agents

* Master Orchestrator
* Travel Optimization Module
* Packing Recommendation Agent
* CRM Suggestion (Mocked)
* Safety Info Module
* Expense Classification (Rule-based + AI simulation)

* Real flight booking
* Real hotel APIs
* Live payment integration

* Show orchestration
* Show cost comparison
* Show policy enforcement
* Show explainability
* Show edge case handling

## 4. Edge Cases to Demonstrate

* Budget exceeded scenario
* Multiple travelers optimization
* Policy violation detection
* Emergency simulation
