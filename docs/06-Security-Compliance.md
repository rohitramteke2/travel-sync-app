# Security & Compliance

## 1. Security Architecture

* Zero-trust communication model
* Role-Based Access Control (RBAC)
* Policy validation before booking
* Immutable audit logs

---

## 2. Data Protection

* Encryption at rest (AES-256)
* Encryption in transit (TLS 1.3)
* Tokenized sensitive fields
* Controlled access to expense data

---

## 3. Compliance Alignment

* GDPR principles
* Data residency awareness
* Corporate travel policy enforcement

---

## 4. Audit Trail

Every:

* Booking decision
* Expense classification
* Policy override
* Safety escalation

Is logged with timestamp and reason.
