# Operations Guide

## 1. Operations Dashboard

Modules:

* Trip Command Center
* Approval Queue
* Expense Dashboard
* Alert Center
* Policy Manager

---

## 2. Approval Workflow

Auto-Approved if:

* Within budget
* Within policy
* Advance booking

Manual Review Triggered if:

* Budget exceeds threshold
* Premium class request
* High-risk destination

---

## 3. Exception Handling

### Flight Delay

* Detect delay
* Suggest rebooking
* Notify traveler

### Emergency

* Trigger escalation protocol
* Notify manager + security
* Provide local contacts

---

## 4. Post-Trip Reconciliation

T+0: Draft report generated
T+1: Traveler review
T+2: Operations approval
T+3: Finance processing
