# Notification Agent

## Purpose

Acts as the unified communication layer of the system.

---

## Responsibilities

* Send booking confirmations
* Deliver approval requests
* Push safety alerts
* Notify policy violations

---

## Channels (Production Vision)

* Email
* SMS
* Push notifications
* WhatsApp

---

## Inputs

* Event trigger
* Message payload
* Escalation level

---

## Outputs

* Delivery confirmation
* Escalation confirmation

---

## MVP Note

Notifications are simulated within dashboard UI.
