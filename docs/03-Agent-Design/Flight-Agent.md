# Flight Booking Agent

## 1. Purpose

Responsible for evaluating flight options and recommending the most policy-compliant and cost-efficient route.

---

## 2. Responsibilities

* Compare flight vs train (MVP simulated)
* Evaluate cost and travel time
* Enforce fare class policy
* Provide savings comparison

---

## 3. Inputs

* Origin
* Destination
* Travel date
* Team size
* Policy constraints

---

## 4. Outputs

* Mode options
* Cost breakdown
* Time comparison
* Recommended option

---

## 5. Decision Logic

* Cost per traveler × team size
* Time efficiency factor
* Budget threshold check
* Advance booking rule

---

## 6. Edge Case Handling

* Large group travel optimization
* Budget exceeded scenario
* No direct route available

---

## 7. MVP Note

Booking execution is simulated. Decision engine is real.
