# Transport Agent

## Purpose

Handles ground transportation planning and tagging for expense tracking.

---

## Responsibilities

* Estimate airport transfers
* Suggest cab pooling
* Categorize commute type

---

## Inputs

* Destination
* Team size
* Trip duration

---

## Outputs

* Estimated local transport cost
* Mode suggestion
* Expense category tag

---

## Decision Logic

* Team pooling optimization
* Time vs cost trade-off

---

## MVP Note

Transport costs are simulated using predefined matrix.
