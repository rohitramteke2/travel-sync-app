# Expense Tracker Agent

## Purpose

Captures, classifies, and validates travel expenses.

---

## Responsibilities

* Categorize expenses
* Separate personal vs business
* Validate against policy limits
* Generate structured report

---

## Inputs

* Expense entry
* Merchant category
* Amount
* Timestamp

---

## Outputs

* Expense category
* Policy compliance flag
* Personal/business classification

---

## Classification Signals

* Location context
* Time-of-day
* Policy cap comparison

---

## MVP Note

Uses rule-based logic with AI-simulated explanation layer.
